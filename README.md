## CodeForces_TLE

This repository documents my **consistent problem solving journey in Data Structures and Algorithms**.
It focuses on daily practice to eliminate TLEs and improve logic, along with **competitive programming contest problems from Codeforces**.

Consistency and discipline are the core goals of this repository.

🌿 Branch Structure

This repository is organized using branches to keep different types of work cleanly separated.

### 🔹 `main` branch

* Daily problem solving
* TLE Eliminator streak
* Concept focused practice
* Solutions written with clarity and learning in mind

### 🔹 `contest` branch

* **Codeforces contest solutions only**
* Problems solved during live contests
